# Помощник ведущего «Мафии»

Приложение для ведущего игры «Мафия» на телефоне: раздача ролей, ночные этапы, обсуждение с таймером, подсчёт голосов, журнал партии. Девять сюжетов со своим оформлением и звуком.

Открыть: https://arsenii09007-coder.github.io/mafia/

Всё приложение — один файл `index.html`. Он работает и без интернета, если открыть его в браузере.
